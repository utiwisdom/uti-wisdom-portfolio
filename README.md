# Uti Wisdom | Data Engineer Portfolio

A single-page portfolio. One HTML file, no frameworks, no build step.

Live: https://utiwisdom.netlify.app/

## Files
- `index.html`: the whole site (HTML, CSS, JS)
- `wisdom.jpg`: your profile photo (replace with your real one, same name)
- `og.png`: social share image (1200x630)
- `favicon.svg`: backup favicon file
- `robots.txt`: lets search engines index the page
- `netlify.toml`: tells Netlify to publish the repo root

## Run locally
Open `index.html` in a browser.
